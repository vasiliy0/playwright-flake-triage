# Security and Privacy

This tool is designed to run locally and read test reports/logs only.

## Sensitive data warning

Playwright reports and CI logs may contain:

- Internal URLs and hostnames.
- User identifiers or test account data.
- Tokens accidentally printed by test code.
- Proprietary product flows or selectors.

Review generated reports before sharing them publicly.

## Reporting issues

If this is published later, security reporting instructions should be updated with the approved contact/channel. Until then, keep reports local.
